caxgauge sample reports

Each report is the output of caxgauge check on one exported STL: deterministic checks beside a four-view render. The verdict is only fail or review — never "pass".

Green is necessary, not sufficient: these checks cannot see local defects. Look at the render and decide.

Benchmark pilot: build123d vs OpenSCAD

Five written briefs, each with bounds declared before any run; an agent (claude -p, Claude Sonnet 5.5) wrote each part three times in each tool. All 30 runs produced a part and passed preflight — which only means nothing was obviously broken. Whether each part is actually right is decided by looking at its views.
